# Вместе

Небольшой сайт совместного просмотра, подходящий для статического GitHub Pages. HTML/CSS/JavaScript без сборки. Единственная внешняя библиотека — PeerJS 1.5.5 через jsDelivr, сигнализация через бесплатный PeerJS Cloud.

## Как смотреть

1. Ведущий открывает сайт и нажимает «Создать комнату».
2. Копирует приглашение и отправляет друзьям. Ссылка содержит секрет доступа; не публикуйте её для посторонних.
3. Выбирает «Тестовое видео», прямую HTTPS-ссылку на MP4 или локальный файл.
4. Участники открывают приглашение. Если выбран файл, каждый открывает одинаковую копию с тем же именем и размером у себя. Файл не передаётся и не загружается на GitHub. Имя и размер не доказывают идентичность содержимого.
5. На телефоне участник нажимает «Включить просмотр и звук». Пуск, пауза, перемотка и скорость задаются ведущим. Коррекция времени проходит каждые две секунды, с оценкой разницы часов по ping/pong.

Комната поддерживает до 8 зрителей. Чат хранится только в памяти открытой страницы (до 100 сообщений). Ведущий должен держать страницу открытой; обновление или закрытие завершает комнату. Верните фокус вкладке после переключения приложений на телефоне.

### Если PeerJS не подключается

При проверке 14 октября 2026 сервер PeerJS Cloud блокировал текущий IP через Cloudflare (HTTP 403). Поэтому предусмотрено прямое WebRTC-соединение без сервера сигнализации:

1. Ведущий нажимает «Создать прямую комнату», затем «Скопировать приглашение».
2. Друг открывает ссылку, копирует появившийся код ответа и отправляет его ведущему.
3. Ведущий вставляет код в «Ответный код от друга» и нажимает «Подключить».
4. Для каждого следующего друга ведущий генерирует отдельное приглашение. Неиспользованные приглашения истекают через 5 минут.

Дальше чат и синхронизация работают по тому же протоколу. Приглашение содержит сетевые параметры WebRTC; передавайте его только участникам. Без TURN прямое соединение может не пройти между отдельными мобильными сетями.

## Видео

«Бесстыжие» не включены: проверенного доступного источника серий с русской озвучкой для этого плеера пока нет. Карточка [Wink](https://wink.ru/series/besstyzhie-year-2011) при проверке сообщала, что сериал недоступен. Произвольные страницы кинотеатров не являются прямыми видеоисточниками; их закрытые плееры не интегрированы.

Тестовый ролик — пятисекундное CC0-видео [MDN](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4). Для совместимости с мобильными браузерами используйте MP4 H.264/AAC. MKV и некоторые кодеки браузер может не воспроизвести. Прямой URL должен быть доступен всем участникам; временные ссылки могут истечь.

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория `SDeeKey/raveCopy`, затем в **Settings → Pages → Deploy from a branch** выберите основную ветку и `/ (root)`. Сборка и npm install не нужны. Ожидаемый адрес после успешного развёртывания: `https://sdeekey.github.io/raveCopy/`.

## Ограничения

Это прототип, не гарантия работы во всех сетях. PeerJS Cloud и CDN — внешние бесплатные сервисы. Собственного TURN-сервера нет; сложные NAT, корпоративные сети и мобильные операторы могут препятствовать соединению. Для стабильной работы в таких сетях потребуется TURN. Мобильная ОС может приостановить фоновые вкладки. Видео буферизуется отдельно у каждого участника; автопауза всей комнаты при буферизации не реализована. Восстановление после ухода ведущего, голосовая связь, хранение видео и интеграция DRM-кинотеатров не реализованы.
